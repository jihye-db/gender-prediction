# 백화점 고객 성별 예측(머신러닝 개인 컴피티션)

백화점 고객의 나이·구매금액·상품·색상·결제수단·할인여부 등 18개 변수로 성별을 예측했다. 최종 순위가 미공개 Private 데이터로 정해지는 대회라, 진짜 과제는 정확도 자체보다 Public 리더보드에 과적합되지 않고 Private에서 무너지지 않는 모델을 만드는 것이었다.

## 데이터에서 찾은 신호
EDA에서 성별이 남성 68%로 불균형이라는 걸 확인하고, 변수별로 성별과의 연관성을 뜯어봤다. 그 결과 Discount, Promo Code, Subscription 같은 혜택 플래그가 성별을 사실상 결정한다는 걸 발견했다(혜택=Yes면 남성 100%). 반대로 고객의 56%는 성별이 통계적으로 무작위였다. 겉보기엔 상품별로 성별 차이가 나는 것 같았지만, 사실은 할인 신호에 의한 착시(confounding)였다.

## 직관을 데이터로 반증
"핑크=여성, 블라우스=여성" 같은 통념은 이 데이터에선 성립하지 않았다. 오히려 이런 직관적 피처를 넣으면 Private 점수를 깎는 과적합 함정이라는 걸 정량적으로 확인했다.

## 검증 설계 (이 프로젝트의 핵심)
단순 교차검증이 낙관적으로 편향될 수 있다는 걸 경계하고 여러 층의 검증을 설계했다. 반복 층화 교차검증(Repeated Stratified K-Fold)으로 안정적인 점수를 얻고, 피처를 짝지어(paired) 비교해 순효과를 재고, 순열 검정(permutation)으로 신호가 진짜 있는지 판정하고, 손대지 않은 홀드아웃으로 인코더 편향을 걸러냈다. 피처 선택도 폴드 내부에서 해서 검증 누수를 막았다.

## 피처 선택
77개 피처 후보를 "손대지 않은 홀드아웃에서 개선이 있고 승률 65% 이상"이라는 규칙으로 스크리닝했다. 감이 아니라 이 기준으로 채택과 폐기를 정했고, 통과한 pay_matches_pref 하나만 추가해 AUC가 0.8144에서 0.8194로 올랐다. 나이·구매금액·상품·색상·사이즈 같은 직관적 후보는 전부 검증에서 이득이 사라져 폐기했다.

## 모델
모델 8종(LogReg, RF, ExtraTrees, GBM, HistGB, XGBoost, LightGBM, CatBoost)과 인코더 8종을 비교한 뒤, 보정된 로지스틱 회귀에 10-시드 앙상블을 얹은 게 가장 견고했다. 최종 ROC-AUC 0.819, Public 과적합 없이 Private에서 안정적으로 나왔다.
